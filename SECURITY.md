# Security policy

Security fixes target the latest published version of each npm package. Older
versions are not maintained; upgrade to the latest release before reporting.

Please report suspected vulnerabilities privately to **neuralsoft@gmail.com**
with the affected package/version, reproduction steps, impact, and any proposed
mitigation. Do not open a public issue with exploit details. Coordinate disclosure
with the maintainer so a fix can be made available first.

Releases use GitHub Actions and npm trusted publishing. Never include credentials,
access tokens, or private material assets in a report or test fixture.
